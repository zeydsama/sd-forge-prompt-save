# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - Initial Release

### Added
- **Native Extra Networks UI integration**: Added a dedicated "Prompts" tab alongside Checkpoints and Loras.
- **Visual Prompt Gallery**: Display prompts as visual cards using user-uploaded `.png` images.
- **One-Click Application**: Send positive and negative prompts straight to generation textboxes by clicking on the prompt card.
- **Integrated Save Prompt UI**: A streamlined popup UI designed for rapidly creating new prompts directly inside the Prompts Extra Networks tab via a new **"+"** button.
- **In-App Editing**: Full integration with the Extra Networks Metadata Editor. Hover over cards and click the pencil icon to tweak positive and negative prompts dynamically without leaving the UI.
- **File System Cleanliness**: Automatically saves `.json` and `.png` data safely under `models/saved_prompts/`.
